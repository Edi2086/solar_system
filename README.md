# Solar Observatory
A detailed interactive 3D solar system built with Three.js. All rendering libraries and planet textures are served locally.

Run `python3 -m http.server 8000 --directory dist`, then visit http://localhost:8000.

Features: eight planets and Sun, 2K surface textures, atmospheric rims, Saturn's rings, Earth’s Moon, asteroid belt, star field, planet focus and camera tracking, orbital paths, labels, pause and speed controls, touch support.

Sizes and distances are compressed for exploration. Orbital positions are artistic, not an ephemeris. Orbital speeds are compressed for visual accessibility.

Textures: Solar System Scope (https://www.solarsystemscope.com/textures/), CC BY 4.0. Rendering: Three.js, MIT license. Fonts: Google Fonts (optional; system fallbacks available).
